# HPFL Fantasy Football

## Project purpose
Optimize keeper decisions, auction strategy, and in-season management for
Xavier's Force in the HPFL — a 16-team CBS salary-cap keeper league.

## Key docs
- `MONEYBALL_POLICY.md` — sport-agnostic fantasy principles (shared across leagues)
- `LEAGUE_PROFILE.md` — HPFL-specific rules, roster, and season plan
- `data/` — raw roster exports and analysis outputs

## Workflow
1. Always follow the Moneyball Policy; when it conflicts with the League Profile, the League Profile wins.
2. **Never recommend a keeper, cut, or auction target without verifying the player's current real-world status** (team, injury, depth chart) via web search.
3. Date-stamp every analysis. A July plan is a draft — recheck before deadlines.
4. Show the math: surplus value = (projected auction price) − (keeper cost).
